# 🍜 NIASE Tomyam Street Food Website

Welcome to the official repository for the **NIASE Tomyam Street Food Website**! This is a multi-page web development project designed to digitally showcase the brand's menu, customer testimonials, and operational information.

The website is now **LIVE** and can be accessed here:
👉 [Visit NIASE Tomyam Street Food](https://nrimm04.github.io/NIASEE-TOMYAM/)

---

## 🚀 Features

*   **Seamless Navigation**: Features 6 main interconnected pages with fully functional navigation links.
*   **Interactive Menu Gallery**: Showcases high-quality images of dishes to attract potential customers.
*   **User-Friendly Layout**: Includes a dedicated FAQ page for common inquiries and a structural "Contact Us" section.

---

## 📂 File & Folder Structure

The project directory is organized as follows to ensure proper routing and asset loading:

| File / Folder Name | Description / Function |
| :--- | :--- |
| `index.html` | The landing/home page introducing the NIASE Tomyam brand. |
| `menu.html` | The full menu listing all available street food dishes and drinks. |
| `best seller.html` | A dedicated page highlighting the crowd's favorite items. |
| `customers.html` | The testimonials and reviews page showcasing customer feedback. |
| `contact us.html` | Contains shop location, operating hours, and contact details. |
| `FAQ.html` | Frequently Asked Questions page for quick customer help. |
| `Image mia.html/` | Asset folder containing specific images and graphics (Set A). |
| `image fana.html/` | Asset folder containing specific images and graphics (Set B). |

---

## 🛠️ Technologies Used

*   **HTML5** - Used to structure the content and layout of all 6 web pages.
*   **CSS3** - Used for custom styling, visual design, and color palettes.
*   **GitHub Pages** - Used as the free hosting platform to deploy the project live.
